# Weekly Reminder Life Telegram Bot

Телеграм-бот, который отправляет пользователям еженедельные напоминания о том, сколько недель они прожили с момента рождения.

## Особенности

- Регистрация пользователей с указанием имени и даты рождения
- Еженедельные уведомления по воскресеньям в 21:00
- Календарь жизни с визуализацией прожитых недель
- Статистика жизни с подробной информацией
- Редактирование профиля (имя, дата рождения, ожидаемая продолжительность жизни)
- Управление уведомлениями (включение/отключение)
- Хранение данных в SQLite базе данных
- Контейнеризация с помощью Docker
- Полное покрытие тестами

## Команды бота

- `/start` - Начать работу с ботом и зарегистрироваться
- `/register` - Регистрация нового пользователя
- `/stats` - Показать статистику жизни
- `/calendar` - Показать календарь жизни
- `/edit_profile` - Редактировать профиль
- `/notifications` - Управление уведомлениями
- `/delete_profile` - Удалить профиль
- `/help` - Показать справку по командам

## Запуск с использованием Docker

### Сборка и запуск с помощью docker-compose

1. Убедитесь, что у вас установлены Docker и docker-compose
2. Клонируйте репозиторий
3. Запустите контейнер:

```bash
docker-compose up -d
```

Для просмотра логов:

```bash
docker-compose logs -f
```

### Сборка и запуск вручную

1. Соберите Docker-образ:

```bash
docker build -t weekly-reminder-bot .
```

2. Запустите контейнер:

```bash
docker run -d --name weekly-reminder-bot \
  -v $(pwd)/data:/app/data \
  weekly-reminder-bot
```

## Настройка

Перед запуском необходимо указать токен вашего Telegram-бота в переменной окружения `BOT_TOKEN`. Вы можете получить токен у [@BotFather](https://t.me/BotFather).

### Настройка токена

1. В файле `docker-compose.yml` укажите ваш токен в переменной окружения:

```yaml
environment:
  - BOT_TOKEN=ваш_токен_бота
```

2. Или при запуске вручную укажите переменную окружения:

```bash
docker run -d --name weekly-reminder-bot \
  -v $(pwd)/data:/app/data \
  -e BOT_TOKEN=ваш_токен_бота \
  weekly-reminder-bot
```

## Разработка

### Локальный запуск без Docker

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` с токеном бота:

```
BOT_TOKEN=ваш_токен_бота
```

3. Запустите бота:

```bash
python bot.py
```

## Тестирование

Для запуска тестов используйте pytest:

```bash
# Установка pytest (если не установлен)
pip install pytest pytest-mock

# Запуск всех тестов
pytest test_bot.py -v

# Запуск тестов с покрытием
pip install pytest-cov
pytest test_bot.py --cov=bot --cov-report=html
```

Тесты покрывают все основные функции бота:
- Подключение к базе данных
- Регистрацию пользователей
- Генерацию статистики и календаря жизни
- Редактирование профиля
- Управление уведомлениями

## Структура проекта

- `bot.py` - основной файл бота
- `test_bot.py` - тесты для всех функций бота
- `requirements.txt` - зависимости проекта
- `Dockerfile` - инструкции для сборки Docker-образа
- `docker-compose.yml` - конфигурация для docker-compose
- `data/` - директория для хранения базы данных (создается автоматически)

## Данные

База данных SQLite (`weekly_reminder.db`) хранится в директории `data/` и сохраняется между перезапусками контейнера благодаря использованию Docker-тома.
